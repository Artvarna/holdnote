# Theses

One file per thesis, `TICKER-YYYY-MM-DD.md`, written before you buy (or
afterwards, for something you already own). BuffettBot writes them from your
own words through Buffett's four questions and never edits one afterwards: a
changed view is a new dated file beside the old one.

Say "write a thesis for <ticker>" to start one, or "check my <ticker>
thesis" to test it against the newest filing.
