# Profile

Your preferences. BuffettBot reads this file at the start of every run and
never changes it unless you ask. The setup conversation ("set up BuffettBot")
fills it in for you.

## Settings

| Setting | Value | What it does |
|---|---|---|
| Name | | How reports address you; leave blank for none |
| Base currency | EUR | Currency portfolio values are shown in |
| Broker | Trading 212 | Trading 212 exports are read automatically; any other broker: fill `portfolio.md` by hand |
| Report length | short | `short` = the rendered report; `full` = every detail table too |
| Default lenses | Buffett | Lenses every brief runs; Buffett always runs. Add e.g. `Graham, Lynch` |
| Buffett notes | on | One or two principles from Buffett's letters when a finding matches one |
| Language | English | Language of the report text |

## Circle of competence

The industries you understand well enough to judge a company in them.
Buffett's advice is to know where this circle ends and stay inside it. A brief
on a company outside it says so in a Buffett note. One industry per line, in
GICS sector names (Information Technology, Financials, Health Care, ...).

Anything else it should know: your investing horizon, what you want
